## 🛠️ ឧបករណ៍និងការងាររួម

### 1. Class `khmermath.cls`

class LaTeX ផ្ទាល់ខ្លួន ដែលបង្ហាញទិដ្ឋភាពទាំងអស់ក្នុងឯកសារ (ហេតុនេះ `.cls` ត្រូវដាក់ក្នុងថតម្នាក់ឯងជាមួយឯកសារ `.tex` របស់វា)។

```latex
\documentclass[theme=teal]{khmermath}
```

**ជម្រើសសំខាន់ៗ** ដែលប្រើជាញឹកញាប់៖

| ប៉ារ៉ាម៉ែត្រ | ប្រើសម្រាប់ |
|---|---|
| `theme=teal` | ពណ៌ប្រធានបទសំខាន់ៗ (teal / dark teal / beige / orange) |
| `\geometry{left=0.8cm, right=0.8cm, top=0.35cm, bottom=0.85cm}` | កំណត់ស៊ុមទំព័រសម្រាប់លំហាត់ស្ទាត់បំផុត |
| `\everymath{\displaystyle}` | ធ្វើឲ្យរូបមន្តគ្រប់ប្រភេទបង្ហាញជាទម្រង់ធំ (display) |

**ពណ៌មេរៀន** ដែលបានប្រកាសក្នុង class៖

| ឈ្មោះ | RGB | ប្រើសម្រាប់ |
|---|---|---|
| `koreaTeal` | `0, 150, 155` | ប្រធានបទសំខាន់ |
| `koreaBeige` | `247, 244, 237` | ប្រអប់ទ្រឹស្ដីបទ (concept sidebar) |
| `koreaOrange` | `235, 115, 30` | លេខបញ្ហា |
| `koreaBlue` | `35, 110, 190` | ស្លាកសម្គាល់ធម្មតា |
| `koreaPurple` | `125, 50, 160` | ការរំលឹកសំខាន់ៗ |
| `koreaYellow` | `255, 246, 175` | ពណ៌បន្លាសញ្ញាសំខាន់ៗ |

**ឯកសារបន្ថែម** ដែលប្រើរួម៖ `tikz` (គ្រាប់រាងសំរាប់ធរណីមាត្រ) និង `colortbl` (តារាងជាមួយពណ៌)។
